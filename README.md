ground projection.Input Parameters:Live camera feed via OpenCV (cv2.VideoCapture(0) or video loop file).Room zone definition polygons ({"Zone_A": [[x1, y1], [x2, y2], ...]}).Calibration offsets each person a zone_id.Emit the resulting data packet directly in memory via an HTTP POST or a Python callable without reading/writing disk files.Output Deliverable:An automated stream pushing the CV Output Schema payload every $N$ frames to Member N's backend endpoint (/api/telemetry/frame).Part 2: N (Digital Twin Engine, Physics & Interactive UI)Ownership: Central orchestration, physics/energy
